# Aironet マニュアル参照

`manualbook` で変換したローカル資料を読み、根拠を付けて答える。
この参照作業では機器に接続せず、設定も変更しない。

## 対象とトレインを選ぶ

依頼・会話・すでに取得された表示結果から機種、AireOS / Mobility Express / AP の別、
実行版を決める。マニュアルの調査のために SSH 接続して調べない。
実行版が分かる場合はそのトレインを優先する。
不明なら適用範囲を限定して調べ、結論に影響する情報だけ尋ねる。比較の依頼なら両方を読む。

本リポジトリで扱うトレインの目安は次のとおり。実際の版・対応機種は冊子で確認する。

| train | 選択の目安 |
|---|---|
| `8-5` | 2504 / 5508 / 7510 / WiSM2 / 8510 の最終トレイン。ほかの WLC や Mobility Express の 8.5 資料も含む |
| `8-10` | 3504 / 5520 / 8540 / vWLC / Mobility Express の最終トレイン。2504 に適用しない |

最終トレインと実機の実行版は同じとは限らない。機種だけで実行版を断定しない。
IOS XE の Catalyst 9800 用資料として扱わない。

## 資料の場所と冊子を選ぶ

環境変数 `AIRONET_MANUALS` が設定されていればそのパス、未設定なら `~/.aironet/manuals/`
を `<manuals>` とする。指定先が無い場合も別のルートへ黙って切り替えない。
資料は `<manuals>/<train>/<book>/` にあり、冊子の `README.md` でタイトル、版、
出典、取得日、対象機種、章一覧を確認する。

| 調べること | book | 最初に引く索引 |
|---|---|---|
| WLC のコマンド構文・引数・既定値 | `cr`（8-5 / 8-10） | `commands.tsv` |
| WLC の機能・設定手順・制約 | `cg`（8-5 / 8-10） | `sections.tsv` |
| Mobility Express の構成・設定手順 | `me-ug`（8-5 / 8-10） | `sections.tsv` |
| Mobility Express 8.5 の CLI | `me-ug` | `sections.tsv` の `ctrlr_cli#…` |
| Mobility Express 8.10 の CLI | `me-cr` | `commands.tsv` |
| Mobility Express 8.5 の導入 | `me-dg` | `sections.tsv` |
| Mobility Express の対応機種・版固有の制約 | `me-rn`（8-5 / 8-10） | `sections.tsv` |
| AP 自身のコマンド（Wave 2 / Catalyst Wi-Fi6） | `ap-cr`（8-10） | `commands.tsv` |

Mobility Express 8.5 に独立した `me-cr` はない。User Guide の Controller CLI Commands は
手順として記載され、`commands.tsv` に載らないので `sections.tsv` から引く。
`ap-cr` は AP 自身の CLI。WLC や Mobility Express のコントローラー CLI と区別する。

必要な資料が無ければ、不足するトレイン・冊子と探した場所を伝える。
生成方法は aironet の README にある `manualbook build` を案内する。
参照の依頼だけで取得や再変換を始めない。再変換は冊子のディレクトリを削除して作り直す。
手元で確認できた範囲を答え、不足部分を記憶で補わない。

## 索引からトピック全文を読む

索引はタブ区切りで、列は次のとおり。

| 索引 | 列 |
|---|---|
| `commands.tsv` | `command / entry / file / line / source` |
| `sections.tsv` | `section / title / file / line / source` |

コマンドは `command`、機能は `title` を中心に検索する。例えば次のように候補を探せる。
パスは実際のルートと対象のトレイン・冊子に置き換える。

```console
rg -n -i -F "config wlan" "<manuals>/8-10/cr/commands.tsv"
rg -n -i -F "WLAN" "<manuals>/8-10/cg/sections.tsv"
rg -n -F "ctrlr_cli#" "<manuals>/8-5/me-ug/sections.tsv"
```

`file` は冊子ディレクトリからの相対パス、`line` はその本文の見出し行（1始まり）。
`rg -n` が付ける索引内の行番号とは異なる。`section` は「章#アンカー」であり、
ファイルパスではない。ファイル名をコマンド名から推測せず、索引の `file` を使う。

候補のトピックファイルを**全文読む**。1 コマンド・1 機能ごとに分割されているので、
固定の前後数行だけを読んで注記や制約を落とさない。
大きいトピックには分割された子トピックへの一覧リンクがある。関係する子ファイルも全文読む。
背景やグループの位置づけが必要なら章の `README.md` を読む。

構文・引数の順序と範囲・既定値・対象の CLI・実行条件・例・制約を、質問に関係する範囲で確認する。
WLAN の無効化、再起動、保存が必要な条件や、機種・版による例外を落とさない。
表の値には列見出し・単位・脚注を対応させ、図が結論に関係する場合は画像も確認する。
本文中の相対リンクは、その本文ファイルのディレクトリから解決する。

索引に無ければ表記の一部・別名・英語の機能名で `sections.tsv` も検索し、必要に応じて
対象冊子の本文を検索する。本文検索も候補発見のために使い、該当トピックは全文読む。
索引に載るのは所定の構文を持つコマンド項目であり、手順中の CLI まですべて載るわけではない。
見つからないことと非対応であることを区別する。

## 根拠を付けて答える

答えを先に示し、対象機種・参照トレインと版、必要な条件を添える。
索引の `source` は元ページの URL とアンカーなので、その出典へリンクする。
ローカルの根拠を示す場合は `file` と `line` から本文へのリンクを作る。
版の比較では両方の本文を読み、片方に見つからないだけで廃止・非対応と断定しない。
実行版と参照版が異なる場合は、その違いと未確認の範囲を明示する。

マニュアル本文・変換結果・図は手元で参照し、リポジトリに追加したり丸ごと再配布したりしない。
